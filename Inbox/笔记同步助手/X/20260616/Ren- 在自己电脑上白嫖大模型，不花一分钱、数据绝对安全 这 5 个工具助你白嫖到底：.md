在自己电脑上白嫖大模型，不花一分钱、数据绝对安全  
  
这 5 个工具助你白嫖到底：  
  
1、Ollama（174k star）  
  
本地跑模型的标准。  
  
一行命令拉一个模型下来就能用，Llama、Qwen、DeepSeek 都支持，还给别的程序留了接口。  
  
[github.com/ollama/ollama](https://github.com/ollama/ollama)  
  
2、LM Studio  
  
不想碰命令行就用它。图形界面里下载模型、点一下开聊，还能开成本地 API 给别的软件用。  
  
[lmstudio.ai](https://lmstudio.ai)  
  
3、Jan（43k star）  
  
开源版的 ChatGPT 桌面端，全程离线，界面干净，适合当日常本地助手。  
  
[github.com/janhq/jan](https://github.com/janhq/jan)  
  
4、Open WebUI（141k star）  
  
给 Ollama 套一个网页界面，多人、多模型、带知识库问答，体感跟 ChatGPT 一样，自己部署。  
  
[github.com/open-webui/open-webui](https://github.com/open-webui/open-webui)  
  
5、llama.cpp（116k star）  
  
最底层那块基石，上面那些工具很多都靠它，能把大模型压到普通笔记本甚至手机上跑。  
  
[github.com/ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp)  
  
模型在自己机器上，才算真的是你的。

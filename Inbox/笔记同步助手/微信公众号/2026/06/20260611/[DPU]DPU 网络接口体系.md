DPU（数据处理器）的接口体系分为**三大类**，承担数据中心内「服务器 - 网络 - 异构算力」的全链路连接职责，核心目标是通过硬件卸载实现高速、低时延、零 CPU 占用的数据传输。

一、接口整体架构分类

DPU 的接口分为两个核心平面 + 一个辅助平面：

| 接口分类 | 核心作用 | 连接对象 |
| --- | --- | --- |
| **对外网络接口（数据面）** | 服务器与外部网络 / 其他节点的高速数据进出 | 交换机、其他服务器、存储阵列 |
| **主机侧接口（交互面）** | DPU 与本地服务器 CPU/GPU 的控制与数据交互 | 服务器主板 PCIe/CXL 插槽 |
| 管理接口（辅助面） | 带外调试、固件升级、配置管理 | 运维管理网络 |

  

二、核心接口详细说明

### 1\. 对外网络接口（DPU 核心能力载体）

这是 DPU 最核心的业务端口，也是区别于普通 CPU 的关键硬件模块，主流规格如下：

接口类型与速率最主流为**以太网接口**，遵循 IEEE 802.3 标准，覆盖从 10G 到 400G 全规格：

-   入门级：10G/25G SFP28 光口，多用于通用云计算场景
    
-   主流级：100G QSFP28 光口，覆盖大部分企业级数据中心
    
-   高端级：200G/400G QSFP-DD 光口，面向 AI 智算集群高性能计算场景, 额外支持 **InfiniBand 接口**（NDR/HDR 规格，单端口 400G），提供比以太网更低的通信时延。
    

-   **核心硬件特性**
    

-   线速处理：所有接口支持满带宽下的数据包转发，无性能损耗
    
-   多端口聚合：单 DPU 卡通常支持 2～8 个物理端口，可实现链路聚合与冗余
    
-   光 / 电形态兼容：绝大多数为 SFP/QSFP 系列光口，低端型号可选 RJ45 电口
    

### 2\. 主机侧接口（DPU 与本地算力的连接通道）

负责 DPU 与服务器内部 CPU/GPU 的内存交互与控制指令传输：

主流标准：PCIe 接口

-   规格：PCIe 3.0/4.0/5.0，通道数通常为 x8/x16
    
-   带宽：PCIe 4.0 x8 双向带宽 32GB/s，PCIe 5.0 x16 可达 128GB/s
    
-   功能：承担 DPU 卸载任务的数据传输、主机内存的直接访问（DMA）
    

  
-   **下一代标准：CXL 接口**
    
    高端 DPU 逐步支持 CXL（Compute Express Link）协议，实现 CPU 与 DPU 的缓存一致性，适合 GPU / 显存的直接访问，是异构计算场景的主流演进方向。
    

### 3\. 辅助管理接口

通常为 1G/10G 以太网口或 USB 虚拟网口，用于 DPU 的带外配置、固件升级、调试排障，不承载业务流量

三、接口核心技术能力

DPU 的网络接口并非单纯的物理端口，而是集成了完整的硬件加速引擎，核心能力包括：

-   **全栈协议硬件卸载**: 硬件直接处理 L2-L4 层网络协议，包括 TCP/IP 栈、ARP、ICMP，以及 VXLAN/NVGRE/MPLS 等 overlay 隧道协议的封装 / 解封装，OVS 流表转发完全绕开主机 CPU。
    
-   **RDMA : 原生支持**
    

所有高端 DPU 接口原生支持**RoCE（RDMA over Converged Ethernet）** 或 InfiniBand RDMA，实现：

-   零拷贝数据传输：数据直接在节点内存间传输，无需内核参与
    
-   时延降低 90% 以上：AI 集群多卡通信的核心底层技术，支撑大模型分布式训练
    
-   兼容 NVMe-oF：支持分布式存储的远程直接访问
    

-   **一体化卸载能力:** 同一网络接口可同时承载网络、安全、存储三类流量的硬件加速：
    

-   安全：MACsec/IPsec/TLS 加解密卸载
    
-   存储：NVMe-oF、iSCSI 存储协议卸载，数据压缩 / 解压缩

五、典型应用场景

-   **AI 智算集群：200G/400G 接口 + RDMA，支撑多 GPU 节点的高速通信，降低大模型训练的通信时延**
-   **云计算虚拟化：25G/100G 接口 + OVS 卸载，实现租户网络的线速转发，释放宿主机 CPU 算力**
-   **分布式存储：100G 接口 + NVMe-oF 卸载，实现存储池的高速访问，降低存储 IO 时延**
-   **金融低时延交易：25G 低时延接口，实现纳秒级数据包处理，满足高频交易的性能要求**

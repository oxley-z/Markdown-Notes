## **一、为什么二级指针总让人晕？**

先问大家一个问题：**p 是地址，\*p 还是地址？**

以一级指针为例，当我们定义`int num = 10; int *p = #` 时，知道`p` 存放的是`num` 的地址。那`*p` 呢？从语法层面来看，星号是一个解引用操作符，`*` 这个表示方式意味着，`*p` 实际上是要获取由指针`p` 所指向的那个内存地址里存储的具体数值。

因此，`*p` 的值就是10，这个数字正是变量`num` 本身所持有的值，所以，**`*p` 代表的是一个普通的数值结果，而不是一个内存中的地址**。

可是在实际学习的过程里，因为指针这个概念本身是很抽象的，再加上在不同的场景下对指针进行操作的复杂程度很高，所以是非常容易让人产生混淆的情况的。

比如在函数传参时，`void func(int *p)` ，这里的`p` 是指针变量，存的是地址，可传入函数后，对`p` 进行一些操作时，就容易搞不清`*p` 到底代表什么，有时候会错误地认为它还是地址，从而导致程序出现逻辑错误。

在涉及二级指针的学习情境之下，这个问题会被进一步放大，原因在于存在多一层间接性这一情况，因此理解起来会更加困难。

## **二、变量、地址、指针 基础知识**

### **2.1 变量名、内存地址、变量值**

在C语言这个领域里，变量它们的作用，是就像一个个非常神奇的小盒子一样的存在着的，至于说每个小盒子，都是拥有着自己的名字的，那么这个名字我们就把它称之为变量名字的了。

例如，我们进行了定义操作，具体的代码是`int num = 10;`，在此情况下，其中的`num`这一部分就是变量名，这个变量名所起的作用，相当于给对应的这个盒子贴上了一个标签，其目的在于方便我们在程序运行的过程中能够找到它。

那内存地址是个啥东西，它就好比别人说的那个盒子在这个叫做内存的大仓库里头的一个具体的位置号码，计算机的这个内存，是一个挺庞大的一块存储空间，然后这个变量就被存放在了这里面头里面的某一个位置上了，而这个位置的编号，它就是那个内存地址。

变量值则是盒子里装的东西，在`int num = 10;` 中，10 就是变量值 。当我们在程序里使用`num`这个变量的时候，其实是要先通过它的名字去找到它所代表的内存地址，然后再从那个地址里头把存着的变量值拿出来，接着才去做各种操作。

这就像是咱们要找一件具体的物品，得先是借着标签上写的东西来定位那对应的盒子，紧接着再把盒子给打开，从里面掏出装好的东西这样。**变量名是我们和程序进行交互所使用的途径，内存地址是计算机用来存储以及管理变量的手段，而变量值才是我们真正需要去关注的数据内容**。

### **2.2 一级指针 int \*p 到底存了什么？**

一级指针是 C 语言中非常重要的概念。当我们定义`int *p;` 时，这里的`p` 就是一个一级指针变量 。这个变量和普通变量是不一样的。普通变量存放的是确切的数值。

但是这个指针变量存放的并不是具体的值。**它存放的是内存的地址**。具体来说，`int *p;` 表示`p` 是一个指向`int` 类型数据的指针，它可以存放一个`int` 类型变量的地址 。

```
int num = 10;
int *p = #
```

这里先定义了一个`int` 类型的变量`num` ，并初始化为 10 。然后定义了指针`p` ，并通过`&num` 将`num` 的地址赋值给`p` ，此时`p` 就指向了`num` 。可以把这个指针想象成是一张纸，这张纸上头写着某个地址。

要是你手里拿着这么一张纸条，那么你就能够去找那个对应的变量。这个指针它厉害的地方在于哪里? 在于借助着它的话，咱们就可以去间接地访问和修改变量里头的值了。这一点呢是为程序的灵活程度和运行效率提供了很大的一个帮助的。

### **2.3 & 取地址与 \* 解引用**

在 C 语言中，`&` 和`*` 是两个，它们与指针，这两个运算符，是，它们的功能，是截然不同的，而且呢，又是相互配合的，就像一对，默契的搭档这样子的。**`&` 是取地址运算符，它的作用是获取变量的内存地址** 。

比如`int num = 10; int *p = #` ，这里的`&num` 就是获取`num` 变量的内存地址，并将这个地址赋值给指针`p` ，让`p` 指向`num` 。这就相当于是说你想要找到某一个地方，你是需要知道这一个地方的具体是什么地址的，而那个符号 `&` 它就可以帮助你把这个具体的地址给获取到。

现在，而`*`这个符号是一个用来进行解操作的作用的东西，它在专业说法里叫做间接寻址运算符。当把这种运算符放在指针变量身上的时候，它的意思是通过这个指针去找到那个指针所指的那个内存地址，并且拿到存在里面的那个具体的内容与东西。

就拿上面说的那个情况来作为举例，在引入了代码标签里面的内容为p加上一个井号这样的符号之后，就会对接下来出现的一个星号加上代码标签包裹住的字母p的这个整体进行解读，它现在的意思是指过去访问那些被指定的叫做p的指针所指向的一个内存地址里面的东西，而这个所谓的内存地址说白了就是变量名num所在的那个存储位置的地址，因此，我们得到的结果就是读取到了这个地址里面存放的实际数值，换句话说就是用星号加上代码标签包裹住的字母p这种方式去表示出来的那个值，实际上就和代码标签包裹住的字母num所代表的那个数值也就是数字10是完全相等的。

如果执行`*p = 20;` ，那么实际上是把`num` 的值修改为 20 ，因为`*p` 代表的就是`num` 。

这就好像你手头握着地址这把钥匙，你用这把钥匙去打开对应的那扇门，然后把门里面摆着的那些东西给搞到手。

**`&` 这个符号的作用，是让程序去获取那个变量本身所在的地址信息，而`*` 这个符号的意思，则是根据已经得到指针里面的地址编号，然后顺着这个地址跑过去，把存放在那里的那个实际数值给找出来并读取得到**。

在使用指针的时候，大家很多时候会先通过右斜杠与ampersand符号去把变量的地址拿过来，然后把它赋值给指针变量，接着呢，再通过那个左星号符号去操作指针所指向的那个具体值。这两个运算符是理解指针的关键，熟练掌握它们的用法，这是学好指针的重要基础。

### **2.4 图解：p、\*p、&p 的关系**

为了更直观地理解`p` 、`*p` 、`&p` 的关系，我们来看下面这张图：

```
+--------+
| num    | 变量num，值为10
+--------+
    |
    |  &num，num的地址，假设为0x1000
    v
+--------+

    |

    v
+--------+
|  *p    | 等价于num，值为10

    v

```

`p` 是指针变量，它存放的是`num` 的地址 0x1000 ，通过`p` 可以找到`num` 的位置 。

`*p`这个表达式的意思是拿这个指针做一次解引用，简单来说就是要去访问它当前指向的那个内存地址里面到底存了什么数据。

这里指向的地址是0x1000，所以去查这个地方的数据，拿出来的结果就是变量所对应的值十，在这样的一个具体情境下，写法上把\*p直接用num来代替也是完全说得通的，意思是说两者在这里是相等的关系。

`&p` 是取`p` 这个指针变量本身的地址，假设它的地址是 0x2000 ，这是`p` 在内存中的位置，和`p` 所指向的`num` 的地址是不同的概念 。

借由呈现在大家面前的这幅图示，我们期望诸位能够针对 p 以及 \*p 还有 &p 这三者之间的相互关联这一事项，达成一种更加清楚且直观的认知上的提升，因为这项基础性成果的存在，会在你将来去面对并解析二级指针这个概念以及那些难度系数更高的复杂指针应用操作之时，为你带来非常显著的帮助与助力支持。

## _三、核心拆解：p、\*p、\*\*_p 分别是什么？__

### **3.1 p：指针变量本身，存的是地址**

当我们在进行 int p; 这个定义操作的时候，这里说的 p 是一个二级指针变量。它和我们常说的一级指针是有相似之处的，它本身同样被看作是一种变量。不过它所存放的内容并不是一般的数据，而是专门存储了一个一级指针的地址。比方说，存在下面这一段代码的情况:

```
int num = 10;
int *p1 = #
int **p2 = &p1;
```

这个叫做p2的变量，它其实是一个二级指针，它所做的事情，是去存放那个叫做p1的一级指针的地址信息。这就好像 p1 是一张纸条，纸条上写着 num 所在的地址，而 p2 是一张内容更加超级重要的纸条，这张叫做 p2 的纸条上写的，是那张写着 p1 纸条存放位置的信息。

**`p`它是一个指针变量，指针变量在内存里面是占用了空间的，这个被占用的空间里面所存放的东西是什么呢，它所存放的是它所指的那个目标的地址，在这里情况是一级指针的地址，通过得到了这个地址之后，我们是可以找到相对应的那一个一级指针的**。

![[Inbox/笔记同步助手/微信公众号/2026/11/images/227308c4f13cf5db435cc6b207429cf0_MD5.jpg]]

### **3.2 \*p：第一次解引用，得到上一级指针或目标变量**

对二级指针`p`进行第一次解引用，即`*p` ，会得到它所指向的一级指针 。继续上面的例子，`*p2`得到的就是`p1` 。因为`p2`存放的是`p1`的地址，`*p2`就像是拿着`p2`这张超级纸条，找到对应的`p1`纸条 。

如果一级指针`p1`指向的是一个普通变量`num` ，那么`*p2`（也就是`p1`）再进行解引用`*(*p2)`（等价于`*p1`）就可以得到`num`的值 。在这个过程里面，二级指针通过一级指针_**p**__起到了过渡作用_\*，并且它可以用来访问最终的数据。

![[Inbox/笔记同步助手/微信公众号/2026/11/images/7e3d5f62b1c436c14e8c50527efaf406_MD5.jpg]]

### _3.3 \*\*_p：第二次解引用，得到最终数据__

对二级指针`p`进行两次解引用，即`**p` ，就能得到最终存储的数据 。还是以上面的代码为例，`**p2`最终得到的就是`num`的值 10 。具体过程是，`p2`指向`p1`的地址，`*p2`得到`p1` ，再对`*p2`（即`p1`）进行解引用`*(*p2)` ，就得到了`p1`所指向的`num`的值 。

这就好比通过层层查找，先根据`p2`找到`p1`纸条，再根据`p1`纸条找到对应的`num`变量，从而获取到里面的数据 。p这个操作，它是用来获取最终的这种数据的，它是一个关键的步骤，它体现出了二级指针那种间接去访问的一个特性。

![[Inbox/笔记同步助手/微信公众号/2026/11/images/65395666f508e3e4ed5b5a3712713c9b_MD5.jpg]]

把长句子分开来解释, 最外层的 这个符号, 它的意思是说有一个二级指针的存在, 也就是这个指针它专门指向的是另一个指针。

中间的`*`结合`int` ，表示`p`指向的是一个`int *`类型的变量，也就是一个指向`int`类型数据的一级指针 。

最内层的`int`表示最终通过两次解引用后得到的数据类型是`int` 。

## **四、为什么需要二级指针？四个典型场景**

### _4.1 函数内修改外部指针：void func (int \*\*_p)__

在 C 语言里面，函数参数传递这个操作，通常是使用值传递的方式来进行的。这就意味着什么? 这意味着当我们将一个指针作为一个参数传递给函数的时候，在函数的内部，它接收到的并不是你给的那个原始的指针，而是那个指针的一个复制品或者说是一个副本。

如果你去修改这个副本的内容的话，那么是不会对在外面存在的原始指针造成任何影响的。我们假设有下面这样一个代码的样子:

```
#include 
#include 

void allocate(int *ptr) {
    ptr = (int *)malloc(sizeof(int));
}

int main() {
    int *p = NULL;
    allocate(p);
    if (p == NULL) {
        printf("内存分配失败\n");
    } else {
        *p = 10;
        printf("*p = %d\n", *p);
        free(p);
    }
    return 0;
}
```

在上述代码中，`allocate`函数试图为`p`分配内存，但运行后会发现`p`仍然为`NULL` 。这是因为`allocate`函数中的`ptr`是`p`的副本，对`ptr`的修改（如`ptr = (int *)malloc(sizeof(int));`）只改变了副本的指向，而外部的`p`并没有改变 。

为了解决这个问题，我们需要使用二级指针。**通过传递指针的地址，也就二级指针的方式，函数内部就可以修改外部这个指针的指向了**。那么修改后的代码的样子是这样的:

```
#include 
#include 

void allocate(int **ptr) {
    *ptr = (int *)malloc(sizeof(int));
}

int main() {
    int *p = NULL;
    allocate(&p);
    if (p == NULL) {
        printf("内存分配失败\n");
    } else {
        *p = 10;
        printf("*p = %d\n", *p);
        free(p);
    }
    return 0;
}
```

这样，在`main`函数中，`p`就不再是`NULL` ，可以正常使用 。这就是在函数里面去修改外面的那个指针这个场景下，二级指针所具有的重要作用。

### _4.2 动态分配二维数组：int \*\*_arr__

在C语言的世界里头，当我们打算去给那个二维的数组分配动态空间的时候，使用一个二级指针这个方法，是一种比较常见的做法，并且它也是相当有效的，这一点大家都应该知道的。

首先，我们要把静态二维数组的那个定义的流程给捋清楚一下，就像是那个`int arr[3][4];`代码一样，它是在声明的时候就把规模给它定下来了，意思是创建了一个有 3 个行和 4 个列的二维数组，这个数组在各个内存地址上是紧紧挨着、连续地存放好的。

可是呢，如果往后我们遇到了那种情况，就是程序的执行过程里面需要去随时变通分配二维数组的空间了话，那个情形就会完全不一样，会变得有所不同起来。

具体的操作步骤是，利用二级指针来实现对二维数组的动态内存分配。

把行指针数组给分配好，第一步要做的就是拿着 malloc 这个函数去划拉出一块空间来当成是那个指针数组用，那么这个数组里头装了多少个元素，这得按照具体的行数来确定，而且，这数组里的每一根手指头也就是每一个元素它自己都是一个指向内存空间的地址指针，它们的作用就是为了去指好每一行的那一片儿地方，具体怎么弄呢可以参考下面的例子:

```
int rows = 3;
int cols = 4;
int **arr = (int **)malloc(rows * sizeof(int *));
```

这里分配了一个包含`rows`个`int *`类型元素的数组，`arr`是二级指针，它指向这个指针数组的首地址 。

为每一行去分配内存的具体方式是，针对在步骤 1里面所分配的那些指针中的每一个指针，再通过 `malloc`来给它们分别分配出相当于列数大小的那片内存空间，比如存在如下的这样一种情况便是。

```
for (int i = 0; i < rows; i++) {
    arr[i] = (int *)malloc(cols * sizeof(int));
}
```

通过这一步操作，系统就会针对代码中的每一行来执行内存空间的分配动作，为每一行所划分的内存区域配置数量上等于cols的这些值，并且这些被分配的每个数值在类型设定上都统一归于整数型，也就是所谓的int类型。

可以使用动态分配的二维数组，在访问的时候，操作方法和静态二维数组是一样的，比如使用类似于 arr\[i\]\[j\] 这样的方式来进行访问。`arr[i][j]` 这样写是完全可行的。

释放内存这个操作的意思是，当你把那个由动态方式来分配出来的二维数组使用完成之后，你必须去执行释放内存的动作。这样做的主要目的，是为了避免出现内存泄漏这种严重的问题。

关于如何正确地释放内存，有一个先后顺序是需要遵守的，也就是要遵循先释放掉每一行所占用的内存空间这个步骤，然后紧接着再去释放掉那一个专门用来存放行指针的数组所占用的内存空间。作为一个具体的例子来说明这个问题的话，你可以参考以下这种情况:

```
for (int i = 0; i < rows; i++) {
    free(arr[i]);
}
free(arr);
```

使用二级指针去动态分配二维数组，这个做法的好处是它能够根据实际发生的情况，来灵活地安排内存的空间，这和那些静态类型的二维数组不一样，因为静态的二维数组必须在编译器进行工作的时候就把大小定好。

与此同时，这种方法在应对那些不规则的二维数组的时候也显得很方便，什么是一些不规则的二维数组呢? 就是指每一行的列数是可以不相同的这种情况，只要在给每一行分别去分配内存空间的时候，看实际的需要情况来决定列数的多少就可以了。

### _4.3 指针数组与命令行参数：char \*\*_argv__

在 C 语言中，指针数组，它指的是一个数组，这个数组里面的元素，全部都是一份指针。而在二级指针方面常常会被用来操作这样的指针数组，有一个典型的运用场景。就是去处理命令行参数这个问题。

当我们在执行某个 C 语言程序的时候，是通过命令行进行的这种情况。我们可以给当前这。例如，在 Linux 系统中，执行`./program arg1 arg2` ，这里的`arg1`和`arg2`就是传递给`program`程序的参数 。

在C语言程序里面，main`函数`可以拿到两个参数，通常是像下面这样进行定义的。

```
int main(int argc, char *argv[]) {
    // 代码逻辑

}
```

其中，`argc`指的是命令行参数的总数量，这里还需要把程序本身的名称也算在内。例如，执行`./program arg1 arg2`时，`argc`的值为 3 。

`argv`这个东西，它，是一个指那种针的数组，这个数组里面的每一个元素，都是一个指针，这些指针各自指向着各自的命令行参数。**可以将`argv`看作是一个二级指针，它指向一个`char *`类型的数组，数组中的每个元素是一个指向字符串（即命令行参数）的指针** 。

通过`argv参数`，我们现在可以很方便地读取命令行里面的输入内容了。比如说呢，要是想要把所有的命令行参数都打印出来，那么可以使用下面的这一套代码来进行操作。

```
#include 

int main(int argc, char *argv[]) {
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}
```

在这个例子中，`argv[i]`表示第`i`个命令行参数，通过`printf`函数可以将其打印出来 。

在实际应用的场景里面，命令行参数这种东西是经常被拿来用作传递程序在启动运行的时候所需要的配置信息或者文件路径之类的东西的。

打个比方来说吧，假设有那么一个专门用来处理文件的程序，它能够透过命令行参数的形式去接收到到底是要去处理哪一个文件名，然后在这个程序的内部根据接收到的那个文件名再去把相应的文件给打开并进行处理操作。

通过使用二级指针这样一种方式来对命令行参数进行处理的举措，是让程序的交互能力和灵活程度得到了非常显著的大幅提升的效果，这样的做法也完全具备去满足不同应用场景里面对应的各种需求的能力。

### **4.4 链表 / 树操作：插入、删除时修改头指针**

在链表还有树等那些数据结构里面，经常会有需要去改头指针这种状况出现，这个时候二级指针就显示出它的重要性了。我们拿链表来说事儿，这个链表是由一个一个的节点连起来组成的，每一个节点都存有数据，并且还有一个指针是指向后面那个节点的。

然后那个头指针是干嘛用的，它是指向链表的第一个节点，只要通过这个头指针就能访问到整个链表了，它是个入口。

如果我们执行插入操作或者删除操作时，在链表这个场景中间题出现了变化。特别是涉及到修改头指针的时候，情况会变得更加复杂。比如我们在链表的头部去插入一个新的节点，又或者是在链表中去删除掉那个头节点。在这些情况之下，使用一级指针就会无法满足我们的需求了。

这是因为我们在进行函数参数传递时采用的是值传递这种方式。当我们把头指针作为参数传给我们要调用的函数时，函数的内部接收到的其实是那个头指针的一份副本。如果我们对这份副本进行了修改的话，是不会影响到外部的、最原始的那个头指针的。

假设这里有下面这样很简单的链表结点定义还有插入函数，这个是使用了一级指针的，这里面存在的问题:

```
#include 
#include 

// 链表节点定义
typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 向链表头部插入节点（错误示范）
void insert(Node *head, int value) {
    Node *newNode = (Node *)malloc(sizeof(Node));
    newNode->data = value;
    newNode->next = head;
    head = newNode; // 这里修改的是head副本，外部头指针未改变
}

int main() {
    Node *head = NULL;
    insert(head, 10);
    if (head == NULL) {
        printf("链表为空，插入失败\n");
    } else {
        printf("头节点数据: %d\n", head->data);
    }
    return 0;
}
```

在上述代码之中，那个名为insert的函数，它本来是想要在那个链表的头部去插入一个全新的节点的，可是当程序运行完了之后呢，你会发现那个head节点依然还是null这个状态的，所以很明显的那就是，这个插入这样的一个操作它是没有成功的。

这是因为`insert`函数中的`head`是外部`head`的副本，对`head`的修改（如`head = newNode;`）只改变了副本的指向，而外部的`head`并没有改变 。

为了解决这个问题，我们需要使用二级指针 。通过传递头指针的地址（即二级指针），函数内部就可以修改外部头指针的指向 。修改后的代码如下：

```
#include 
#include 

// 链表节点定义
typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 向链表头部插入节点（正确示范）
void insert(Node **head, int value) {
    Node *newNode = (Node *)malloc(sizeof(Node));
    newNode->data = value;
    newNode->next = *head;
    *head = newNode; // 通过二级指针修改外部头指针
}

int main() {
    Node *head = NULL;
    insert(&head, 10);
    if (head == NULL) {
        printf("链表为空，插入失败\n");
    } else {
        printf("头节点数据: %d\n", head->data);
    }
    return 0;
}
```

在这个版本中，`insert`函数的参数是`Node **head` ，`main`函数中传递的是`&head` ，即`head`的地址 。在`insert`函数内部，`*head`就是外部的`head`本身，通过`*head = newNode;`就可以成功修改`head`的指向，使其指向新插入的节点 。

结果是，在标签对应的代码片段里，`head`这个变量就不再等于`NULL`了，这就意味着插入操作已经完成并且成功了。

在涉及到树这种数据结构的操作环节当中，特别是在执行诸如插入新节点或者删除根节点这样的任务之时，开发者会碰见与之相似的状况。正因为如此，为了能够保证有实力去正确修改掉那个指向根节点的指针本身，就必须得借助使用二级指针这一种方法来实现具体的目的。

之所以要在进行链表和树等等诸多数据结构的操作期间采用二级指针，其根本原因就在于此法可以切实有效地确保对关键性指针的修改行为得以顺利完成。这些被提及的关键性指针，其中就包括被称为头指针的元素，也包括被称作是根节点指针的那些特定变量。

通过上述手段的运用，可以使得关于数据结构层面的各项操作表现得更加灵活随意，同时也能够获得更高的准确度表现。

## _五、易错点：p、\*p、\*\*_p 常见混淆__

### **5.1 定义时的**_**和使用时的**_**不是一回事**

在C语言这个范畴之内，当开发者去定义指针的时候，还有在使用指针的过程之中的时候，这个符号 \* 所具备的那一种含义，它是极其容易让那些观看的人产生一种困惑和混淆的，这种现象是客观存在的。

**当我们定义指针时，比如`int *p;` ，这里的`*`表示`p`是一个指针变量，它用于声明`p`的类型是指向`int`类型数据的指针** 。简单来说，就是告诉编译器`p`是用来存放`int`类型变量地址的 。这就好比说，我们是要去建造一个专门用来放置特定物品的一种容器。这里所说的特定物品，就是地址。

而那个\*这个符号，它就是用来表示这个容器的一个标记。

**当用户使用指针的时候，比如写出`*p = 10;`这种代码的情况，其中的`*`符号被称之为解引用运算符，它的主要作用是把**

所指向的那个内存地址里面的具体数据给找出来，然后再对着这个数据进行各种各样的操作。此时，`*p`代表的是`p`指向的内存地址中的值 。

如果`p`指向一个`int`类型的变量，那么`*p`就相当于这个变量本身 。就好像我们已经知道了存放物品的容器的存在，这个容器是通过

来代表的，而现在我们需要通过这个容器去取出里面的物品，取出的这个操作是通过\*p来表达的，并且我们要把取出的这个物品使用它。

再看一个例子，`int num = 5; int *p = #` ，在定义`p`时，`*`表明`p`是指针；之后如果有`*p = 15;` ，这里的`*`就是解引用，将`p`所指向的`num`的值修改为 15 。

一定要把在这种情况下和那种情况下这两个状态里面出现的星号符号的不同意思区分得清清楚楚，因为如果你没有把它分明白的话，那么在写那一段计算机程序代码的时候，就很容易会弄出那些不符合逻辑的错误来。

### _5.2 int \*p 与 int \*\*_p 类型差在哪？__

`int *p`和`int **p`在类型上有着本质的区别 。这个`int *p`符号，它的意思是，那个`p`变量，它是一个指向`int`这种类型的数据的，一级指针。。例如：

```
int num = 10;
int *p = #
```

在span标签里写的这里这个词后面紧跟着一个code标签包裹的字符为p的这个部分，存放的是由另一个code标签包裹的字符为num的变量所在的这个地址，然后通过使用code标签包裹的p这个指针的值，就可以实现去间接地访问这个代码块里的num变量的内容，同时也可以对它进行修改操作。

`p`的类型是`int *` ，即指向`int`类型的指针 。

而`int p`表示的意思是说，`p`它是一个指针，这个指针专门被用来存放另一个指针的地址。因为后者也是一个指针，它的类型就是指向整数类型的指针，也就是通常说的二级指针这种情况。比如：

```
int num = 10;
int *p1 = #
int **p2 = &p1;
```

这个值里面存的东西，是 所在的这块存储单元的编号。如果你想通过 这个路径，去拿到 里面装的那个数字，那么你就必须把引用操作做上一圈，一共需要做上两遍这样的解除引用的动作，最后才能最终触碰到那个数值本身。

`p2`的类型是`int **` ，即指向`int *`类型指针的指针 。

从内存的角度这个层面来进行分析，指针p，它的类型声明是`int *`，在计算机的内存空间里面它肯定是会占用一定的存储空间位置的，通常情况下呢，如果你是在32位的系统环境之下运行，那么它占据的大小是4个字节，但是如果你是在64位的系统环境之下，那么它占据的空间大小就是8个字节了，之所以要这样设置，目的就是为了用来存放那些类型为`int`的变量所对应的内存地址信息。

而且，`int p` 也会占据具体的存储空间，这个空间的作用是用来存放那些类型为int \*的指针所对应的地址信息。至于在进行所谓的指针相关操作的时候，大家必须非常清楚自己所操作的指针具体属于什么类型，如果不够清楚这一点的话，很可能会因此引发一些因为类型对不上号而导致的错误问题。

打个比方说，要是把一种叫作 int 乘以星号的指针类型的数据，硬塞给另一种叫作 int 乘以两个星号的指针类型去接住，编译器就会报错，让你无法通过审核。

明白这两个东西在类型上面的差别，才是你能够正确地去使用指针的重要基础所在。比如将一个 `int *` 类型的指针赋值给 `int`类型的指针，就会出现编译错误。理解它们的类型差异是正确使用指针的重要基础。

### _5.3 \*p 修改的是谁？\*\*_p 修改的又是谁？__

我们拿个具体的例子来看看，比如说现在有下面这一段代码存在。

```
int num = 10;
int *p = #
int **p2 = &p;
```

对于`*p` ，它修改的是`p`所指向的变量`num` 。例如执行`*p = 20;` ，实际上是将`num`的值从 10 修改为 20 。因为`*p`表示通过指针`p`访问到它所指向的内存地址中的内容，这里就是`num` 。

而对于`**p2` ，它修改的是`p`所指向的`num` ，但中间经过了两次间接访问 。当执行`**p2 = 30;`时，首先`*p2`得到`p` ，再对`p`进行解引用`*(*p2)`得到`num` ，然后将`num`的值修改为 30 。

可以把`*p`想象成直接打开一扇门（`p`指向的门），修改门里面的东西（`num`） 。而`**p2`则像是先找到一个记录门牌号（`p`的地址）的纸条（`p2`），根据纸条找到对应的门（`p`），再打开门修改里面的东西（`num`） 。

在写代码的实际情况里，搞清楚\*p和p到底是在修改哪个对象，这件大事非常关键，因为这样才能让程序功能实现正确，否则就容易蹦出那些让人吓一跳的错误出来。

### **5.4 野指针、空指针、悬空指针与二级指针**

野指针的意思是，它指向的那个内存地址，要么是已经被释放了，要么根本就没有被初始化过。打个比方来说吧，当一个指针变量没有被初始化的时候，那么它所对应的值就是随机的。这样一来就会有可能导致这个指针变成了一个野指针。

如`int *p; *p = 10;` ，这里的`p`没有被初始化就被使用，`*p`操作是未定义行为，很可能导致程序崩溃 。当程序员在使用二级指针的时候，如果对那个指向的一级指针处理得不恰当，那么很有可能会制造出来一个野 指针。

比如说，出现了一个错误情况，就是把一级指针所指向的那块内存给不正确地释放掉了，这时候呢，那个二级指针依然还在指着这个已经被释放掉的一级指针的地址。

空指针是那种值为NULL的指针，在C语言中通常会把它定义成 0，这样的指针它并不指向任何有效的内存地址。例如`int *p = NULL;` ，当我们暂时不需要指针指向任何实际变量时，可以将其赋值为`NULL` 。

在使用二级指针时，也可能出现空指针的情况，比如`int **p2 = NULL;` ，这表示`p2`不指向任何有效的一级指针 。咱们在进行指针操作之前，必须要检查一下这个指针是不是为空的状态，这样就能够有效地避免出现因为空指针去解引用而引发的各种错误。

悬空指针这个概念，指的是说那个指针，它原来指向的那一部分内存空间，已经被给释放掉了，但是呢，这个指针变量本身这块东西，它并没有发生变化，它还是老老实实地保留着那个地址的，只是这个地址现在已经失效了，不再有用处了。

例如，在我们利用了`free`函数把那个指针指向的内存释放掉之后，并没有把这个指针设置成`NULL`这样子的话 ，这个指针就成了所谓的悬空指针。

在二级指针这种场景下，如果一级指针指向的那个内存空间被释放了，但是二级指针没有及时去更新它的内容，这种情况就会引发一个叫做悬空指针的问题存在，下面就是一个具体的例子。

```
int *p = (int *)malloc(sizeof(int));
int **p2 = &p;
free(p);
// 此时p成为悬空指针，p2仍然指向这个悬空指针p的地址
```

在写代码的时候，一定要特别留神，千万要避免出现野指针以及空指针，还有悬空指针，这一点在碰到涉及二级指针的那种复杂操作环节时，更是需要格外小心谨慎地去处理那个指针的指向情况，同时还要仔细地对待内存区域的分配与释放工作。。

### **5.5 传参时为什么有时必须传 & p？**

在调用函数的时候，参数的传递方式通常是值传递。这种机制意味着函数接收到的是参数的一份副本。当我们把一个指针当作参数进行传递的过程中，如果在函数的内部对这个被传递来的指针副本进行了修改动作，那么这种修改行为是不会对外部原本的原始指针产生影响或者造成干扰的。关于这一点可以参见如下的示例代码内容。

```
#include 

void modify(int *p) {
    p = (int *)malloc(sizeof(int));
    *p = 10;
}

int main() {
    int *ptr = NULL;
    modify(ptr);
    if (ptr == NULL) {
        printf("ptr 仍然为 NULL\n");
    } else {
        printf("*ptr = %d\n", *ptr);
    }
    return 0;
}
```

在上述代码中，`modify`函数试图为`ptr`分配内存并赋值，但运行后会发现`ptr`仍然为`NULL` 。这是因为`modify`函数中的`p`是`ptr`的副本，对`p`的修改（如`p = (int *)malloc(sizeof(int));`）只改变了副本的指向，而外部的`ptr`并没有改变 。

为了在函数内部能够对外部指针所指向的位置做出修改这一项操作，我们需要把该指针的地址传递过去。而所谓传递该指针的地址，实际上就意味着我们要使用一个二级指针。例如:

```
#include 
#include 

void modify(int **p) {
    *p = (int *)malloc(sizeof(int));
    **p = 10;
}

int main() {
    int *ptr = NULL;
    modify(&ptr);
    if (ptr == NULL) {
        printf("内存分配失败\n");
    } else {
        printf("*ptr = %d\n", *ptr);
        free(ptr);
    }
    return 0;
}
```

这样，在`main`函数中，`ptr`就不再是`NULL` ，可以正常使用 。所以，当我们需要在函数内部去修改外部的指针的时候，我们就必须把

传递过去，这里的\*p，它就是指的二级指针。

```
    int data;
    struct Node *next;
} Node;

    Node *newNode = (Node *)malloc(sizeof(Node));
    newNode->data = value;
    newNode->next = *head;
    *head = newNode;
}

// 删除头节点
void deleteHead(Node **head) {
    if (*head == NULL) {
        return;
    }
    Node *temp = *head;
    *head = (*head)->next;
    free(temp);
}

// 打印链表
void printList(Node *head) {
    Node *current = head;
    while (current != NULL) {
        printf("%d -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

int main() {
    Node *head = NULL;

    insert(&head, 10);
    insert(&head, 20);
    insert(&head, 30);

    printf("插入节点后的链表: ");
    printList(head);

    deleteHead(&head);
    printf("删除头节点后的链表: ");
    printList(head);

    return 0;
}
```

在这个示例里面，代码里的那个insert这个函数，它是用来在链表这个数据结构的最开始的地方去插入新的节点的，而对应的deleteHead这串英文字符代表的函数，它的作用是用来把链表最前面的那个节点给删除掉。

## **七、画图理解：二级指针的内存布局**

### **7.1 栈、堆、指针变量分别在哪？**

这个在C语言程序里面的内存空间划分得比较明确，主要可以分为这么几块，也就是栈区、堆区、全局区、常量区和代码区这几部分。其中呢栈区是由系统进行自动管理的，它具备一个非常显著的特点，那就是处理速度非常快，所以在实际使用中，通常是用来存储那些局部变量、函数的参数以及返回地址之类的数据内容的。

我们可以这样简单理解其中的一个运行机制，就是每当一个新的函数被调用的时候，程序会在那个栈的区域里为该函数分配出相应的存储空间来放置其内部的局部变量，而当这个函数执行完毕之后，那些原本属于这个局部变量的、现在占据了栈空间的份额，系统就会把它给自主地释放掉。

例如，在函数内部定义的普通变量`int num = 10;` ，`num`就存储在栈区 。

堆区则是用于动态内存分配的区域，需要程序员手动使用`malloc`、`free`等函数来管理 。它的那个空间方面是相对地比较大的，因此是比较适合用来存储那些在运行到了程序时候才能去确定其具体大小的相关数据的，这种数据可以包括一些像是动态进行分配的数组，或者是链表节点等等这样的东西的。

当我们使用`int *p = (int *)malloc(sizeof(int));`时，`p`本身是一个指针变量，它存储在栈区，而通过`malloc`分配的`int`类型的内存空间则在堆区 。

指针变量它本身也是一种变量，所以说，这个指针的变量会就像那些普通的变量一样，要去看它被定义在什么地方了，然后来判定这个存储区到底是哪个区域的。那么，如果这要是函数内部定义的这种指针变量，比如说像代码里面写的那个int \*p这样的东西，它就会被存放在栈区里面的。

如果是全局指针变量，比如在所有函数外部定义`int *gp;` ，那么它存储在全局区 。理解栈区和堆区以及指针变量的存储位置，对于正确管理内存和使用指针非常重要 。

### **7.3 多级指针规律：几颗星，几层跳转**

在 C 语言里面, 多级指针有一个很简单, 但是又非常重要的规律, 这个规律是关于指针定义的, **它提到 \* 符号的数量, 会直接决定指针的层级**, 同时, 它也会直接决定在访问最终数据的时候, 需要进行多少次解引用操作, 也就是说, 星号有几个, 跳转的层级就有几层。

以一个一级指针为例, 这个一级指针是 int \*p; 这样的形式, 这里面的 p 指向了一个类型为 int 的变量, 这时候只需要使用一次解引用操作, 也就是 \*p 就可以访问到那个目标变量的值。

这情形就等同于我们要去寻摸某一样东西, `p`这个东西呢, 简直就像是直接指认该物品所处在哪位置的箭头符号, 借着操作这个箭头（也就是俗称的解引用动作）便能够顺理成章地一下子把该物品给找到。

对于二级指针`int **pp;` ，`pp`指向一个一级指针，需要两次解引用`**pp`才能访问到最终的数据 。

这里`pp`, 现在先指向某个地方, 这个地方里面存放着另一个箭头, 这个箭头就我们常说的一级指针, 大家通过第一次数进行解引用的操作, 能够拿到这一个箭头, 然后再用这个箭头, 也就是这一级指针, 再去进行第二次的解引用操作, 这样才算是找到了那个最终的目标物品。

以此类推，三级指针`int ***ppp;`需要三次解引用`***ppp`才能访问到最终的数据 。每增加一个符号`*`, 事情就会变得更加间接一层, 而在访问数据的时候, 就需要额外执行一次跳转操作。

如果能掌握这一条规律, 对于我们深入理解和实际运用多级指针来说, 是非常有好处的, 并且能够使我们更清楚地看清指针彼此之间的关联情况, 以及获取数据时所经过的具体过程。

### **7.4 为什么三级指针以后很少用？**

在实际的编程工作当中，开发者很少会去用到那些级别达到三级或者比三级还要高的指针，这背后主要有这么几个原因。

首先，我们要说的是可读性这一方面。如果指针的层级越多的话，那么代码的逻辑就会变得越来越复杂。这样的话，在理解和维护代码的时候，大家就会发现这事情就变得越发地困难了。

比如说，对于三级指针`int *p;`这种情况，开发者要是想要搞懂它到底指向哪里，还有数据访问的过程到底是什么样子的，那就必须在脑子里头去搭建一个复杂的内存模型，这会给看代码的人带来非常大的困难，而相比之下，一级指针和二级指针的逻辑就会简单一些，也就容易让人理解一些。

从出错风险这一方面来深入分析，多级指针的实际运用会让事情变得更容易出问题。每一次进行解引用操作的时候，都得去确认这个指针当前所指的具体的内存地址是不是真实存在的，要是没有检查明白的话，那么就很容易出现那些空指针被错误地使用的情况，或者指向了不该指的地方也就是野指针之类的毛病。

你想想，如果指针之间的嵌套层级搞得很多，那想要保证每一层级的指针都完全没有差错，这简直就像是在走钢丝一样困难，而且一旦真的发生了意外，你再回头去找那个该死的bug，也就变得更加艰难和复杂了。

再者，就是在大多数真实使用的过程里边，一级指针以及二级指针就已经足够去满足具体的需要了。举个例子来说，比如需要在函数内部的层面上去改动外部的这个指针，又或者是去进行动态分配二维数组的这种操作，再或者是去处理像链表之类常见的数据时，这时候用二级指针就能够非常圆满地完成既定的任务了。

但是，在极少数的特定场合情况之下，才可能会去涉及到三级或者说是更高级数层面的这一种指针对应的使用频率。

所以，若是从综合考量可读性的高低程度、发生错误风险的大小维度出发，结合实际的客观需求来看待这个问题的话，那么对于三级指针往后延伸的这种高阶指针的使用情况，就会变得非常少见了。

### _8.1 p、\*p、\*\*_p、&p 的区别__

在面试和中，经常会被问到`p` 、`*p` 、`**p` 、`&p`的区别，这也是对指针理解程度的一个重要考查点 。

> `p`：它是指针变量本身，如果是一级指针，它存储的是普通变量的地址；如果是二级指针，它存储的是一级指针的地址 。例如`int *p;` ，`p`就是一个指向`int`类型变量的指针，存放的是`int`变量的地址 。在`int **p;`中，`p`是二级指针，存放的是一级指针的地址 。

> `*p`：是对`p`进行解引用操作。如果`p`是一级指针，`*p`得到的是`p`所指向的普通变量的值；如果`p`是二级指针，`*p`得到的是它所指向的一级指针 。比如在`int num = 10; int *p = #`中，`*p`就等于`num`的值 10 。在`int *p1 = # int **p2 = &p1;`中，`*p2`得到的是`p1` 。

> `**p`：是对二级指针`p`进行两次解引用。它得到的是经过两次指针间接访问后的最终数据 。例如在上述二级指针的例子中，`**p2`得到的就是`num`的值 10 。

> `&p`：是取`p`这个指针变量本身的地址 。无论`p`是一级指针还是二级指针，`&p`获取的都是`p`在内存中的存储地址 。例如`int *p;` ，`&p`就是`p`这个指针变量的地址 。

在回答这类问题时，一定要结合具体的代码示例进行说明，这样会更加清晰明了，让面试官看到你对这些概念的深入理解 。

### **8.2 二级指针作为函数参数的意义**

二级指针在 C 语言里作为函数参数来用的时候，它是有很重要的意义的，而且这也是面试还有考试当中会经常考到的一个点。**它最核心的意义就是能够允许在函数的内部去修改外面那个指针的指向内容**。

之所以会有这样的情况，是因为 C 语言里面的函数参数传递是值的传递方式，当我们把一个指针传给函数的时候，函数里面接收到的其实只是这个指针的一个副本，如果只是在函数里面去对这个副本做修改的话，那是不会影响到外面那个原始的指针的。例如呢，在下面这一些代码的内容当中之中呢:

```
#include 
#include 

void allocate(int *ptr) {
    ptr = (int *)malloc(sizeof(int));
}

int main() {
    int *p = NULL;
    allocate(p);
    if (p == NULL) {
        printf("内存分配失败\n");
    } else {
        *p = 10;
        printf("*p = %d\n", *p);
        free(p);
    }
    return 0;
}
```

`allocate`函数试图为`p`分配内存，但实际上`p`仍然为`NULL` ，因为`allocate`函数中的`ptr`是`p`的副本，对`ptr`的修改没有影响到外部的`p` 。

为了在函数内部能够修改外部指针的指向，所以我们必须使用二级指针。因此，将原来的代码进行修改，具体的修改方式如下所示:

```
#include 
#include 

void allocate(int **ptr) {
    *ptr = (int *)malloc(sizeof(int));
}

int main() {
    int *p = NULL;
    allocate(&p);
    if (p == NULL) {
        printf("内存分配失败\n");
    } else {
        *p = 10;
        printf("*p = %d\n", *p);
        free(p);
    }
    return 0;
}
```

在这个版本中，`allocate`函数的参数是`int **ptr` ，`main`函数中传递的是`&p` ，即`p`的地址 。

在`allocate`函数内部，`*ptr`就是`p`本身，通过`*ptr = (int *)malloc(sizeof(int));`就可以成功修改`p`的指向，使其指向分配的内存空间 。

所以，二级指针被用作函数的参数，这就使得函数具备了对外部的指针执行有效修改的能力，这其中的原因，就是在动态内存分配以及链表操作这类应用场景里非常地重要。在回答那种面试的问题或者是考试问题的过程中，你必须要能够清晰地去阐述上面这个原理，并且还要结合实际的代码示例来加以说明才行。

### **8.3 二维数组和二级指针是一回事吗？**

二维数组和二级指针，它们并不是一回事，虽然在这些场景里面，偶尔会显得有些相似，但是在根本性质上面，可是存在着非常大的区分。

二维数组是在内存里面，它用一块连续的存储空间来保存数据，然后它的元素，是按照行和列的那个顺序，依次地把数据存储起来的。

比如，我们来定义一个二维数组`int arr[3][4];`，这个数组在内存里面的存储状态是连续的，也就是说，所有的`int`类型的那样的元素，它们是按照顺序一个一个地排列在一起的。可以通过`arr[i][j]`的方式来访问数组中的元素，其中`i`表示行下标，`j`表示列下标 。

而二级指针是一个指向指针的指针。当使用二级指针来模拟二维数组时，实际上会先去分配一个指针数组，然后让每个指针再去指向一块独立的内存空间，这些被指向的内存空间就是用来存储数据的。例如:

```
int rows = 3;
int cols = 4;
int **arr = (int **)malloc(rows * sizeof(int *));
for (int i = 0; i < rows; i++) {
    arr[i] = (int *)malloc(cols * sizeof(int));
}
```

这里先分配了一个包含`rows`个`int *`类型元素的数组，`arr`指向这个数组的首地址 。然后为每一行分配`cols`个`int`类型的内存空间。在这种方式之下，每一行的内存是连续的。但是，行与行之间的内存情况就不一定连续了。

从类型的这方面去看的话，二维数组的名字其实它是一个常量，它是一个指针类型，它的作用是指向那个二维数组里面排在最前面的第一个元素，而它的具体的类型是什么呢，它就是 int (\*)\[4\] ，这个是假设那列数刚好等于 4 的情况，这个类型的含义是说，它是一个指针类型，这个指针指向的是一个数组，而这个数组里面的内容是由 4 个 int 这种类型的元素所组成的。

而二级指针的类型是`int **` ，表示指向`int *`类型指针的指针 。

在实际使用的时候，二维数组是更符合存储固定大小的二维数据的场景的，它的内存管理相对就简单了一些。而二级指针就显得更加灵活了，它适合在运行的时候去动态地确定二维数据的大小以及布局情况。

但是，二级指针需要人工去管理内存的分配和释放，这样就增加了出错的风险。因此，在面试和考试当中，要把二维数组和二级指针的概念准确地区分开来才行，避免发生混淆的情况。

### **8.4 malloc 后要不要强转？C 中要注意什么**

在 C 语言这个环境里面，malloc 这个函数是用来做内存的动态分配动作的，它的原型样子就是 void \*malloc(size\_t size); ，它会返回一个指针，这个指针的类型是 void \*类型，而且它指向的是刚刚被分配出来的那块内存区域的起始地址。

关于`malloc`返回值是否需要强转，有以下要点：

在 C 语言中，从`void *`转换成别的类型的指针，是会自动完成的。例如:

```
int *p = malloc(sizeof(int));
```

这里不需要对`malloc`的返回值进行强制类型转换，编译器会自动将`void *`类型转换为`int *`类型 。

然而，在旧式的 C 编译器里，如果一个函数没有原型声明，那么编译器会认为这个函数返回`int`。如果代码里忘记包含头文件（`malloc`函数声明所在的头文件），编译器看到`malloc`调用时，会认为它返回一个`int` 。

在实际运行时，`malloc`的返回值（一个`void *`指针），会被直接解释成一个`int` 。如果这时强制转换这个值，实际就是将`int`直接转换为`void *` ，可能会出现问题，比如`void *`和`int`的长度不同或者编译器不支持这种转换 。

一旦你不对malloc函数所返回的指针结果执行强制类型转换操作，那么编译器在观察到存在将普通的整数类型int转化为整型指针类型int \* 的必要情况时，它就会主动向开发者发出一条相应的警告信息，以此来达到提醒和提示相关风险的目的。

虽然在 C 语言中`malloc`返回值可以不进行强转，但在 C++ 中，强制转换`malloc`的返回值是必须的，否则不能通过编译 。这是因为现在的开发者对于类型检查这一件事情，在利用 C++ 这一编程语言的时候，会感觉到要求变得更加的严格一些。

所以，在 C 语言中使用`malloc`的时候，一般是不需要对返回值进行强制类型转换的，但是，一定要确保包含了这个头文件，这样做是为了避免因为编译器对函数返回值的类型产生了错误的推断，从而引发各种问题。

在面试的时候，要在考试当中的时候，一定要把这几个重点给讲明白，一定要表现出对这个调用函数malloc的使用方法的正确理解。

### **8.5 常见笔试题现场拆解**

接下来，咱们就一起看看一道比较常见的，关于C语言指针的笔试题目。

```
#include 
#include 

void func(int **p) {
    int *q = (int *)malloc(sizeof(int));
    *q = 20;
    *p = q;
}

int main() {
    int *ptr = NULL;
    func(&ptr);
    if (ptr != NULL) {
        printf("*ptr的值: %d\n", *ptr);
        free(ptr);
    }
    return 0;
}
```

题主要求对这段代码的输出结果进行分析，并且还要把产生这种结果的原因给解释一下。

解这个问题的办法，它的具体思路在下面这个地方显示出来了，大家要注意看。

在`main`函数中，定义了一个指针`ptr`并初始化为`NULL` 。

调用`func`函数，传递`&ptr` ，即`ptr`的地址 。在`func`函数中，参数`p`是一个二级指针，它接收了`ptr`的地址 。

在`func`函数内部，首先分配了一块`int`类型大小的内存空间，将其地址赋值给`q` ，然后将 20 赋值给`*q` ，也就是这块新分配内存中的值 。

接着执行`*p = q;` ，因为`p`是二级指针，`*p`就是`ptr`本身，所以这一步将`q`的地址赋值给了`ptr` ，也就是让`ptr`指向了新分配的内存空间 。

回到`main`函数，此时`ptr`不再是`NULL` ，而是指向了分配的内存空间，所以`*ptr`的值为 20 。最后释放`ptr`指向的内存空间，避免内存泄漏 。

所以，这段代码的输出结果是`*ptr的值: 20`。在解答这类笔试题时，必须仔细分析指针的指向情况，需要仔细分析内存的分配情况。要严格按照代码的执行顺序来逐步推理，需要清晰地阐述每一步所执行的操作内容和得出的结果。

## **九、总结：一句话记住二级指针**

### _9.1 p 是地址，\*p 是上一层地址，\*\*_p 是最终值__

通过前面的讲解，我们可以用一句话来简洁地概括：`p`是地址，`*p`是上一层地址，`**p`是最终值 。

以二级指针`int **p`为例，`p`本身是一个指针变量，它存储的是一个一级指针的地址 。`*p`是对`p`进行第一次解引用，得到的是上一层的一级指针，这个一级指针又存储着普通变量的地址 。而`**p`是对`p`进行两次解引用，最终得到的是普通变量的值 。

例如：

```
int num = 10;
int *p1 = #
int **p2 = &p1;
```

这里`p2`存储的是`p1`的地址，`*p2`得到`p1` ，`**p2`得到`num`的值 10 。把这句话牢牢记住，这样就能帮助我们迅速弄清楚它们之间到底有什么关系，到了编写程序的时候，就能表现得更加熟练和自如。

### **9.2 二级指针的本质：为了修改 “指针本身”**

**二级指针的本质作用，是为了在函数内部，或者是在复杂的数据结构操作之中，能够去修改指针本身**。在C语言中，函数参数传递，是采用值传递的方式，当把一级指针当作参数进行传递时，函数内部所接收到的，是那个指针的一个副本，对这一份副本做出的修改行为，是完全不会影响到外部的原始指针的。例如:

```
#include 
#include 

void modify(int *p) {
    p = (int *)malloc(sizeof(int));
    *p = 10;
}

int main() {
    int *ptr = NULL;
    modify(ptr);
    if (ptr == NULL) {
        printf("ptr 仍然为 NULL\n");
    } else {
        printf("*ptr = %d\n", *ptr);
        free(ptr);
    }
    return 0;
}
```

在这个例子中，`modify`函数试图为`ptr`分配内存并赋值，但`ptr`仍然为`NULL` ，因为`modify`函数中的`p`是`ptr`的副本，对`p`的修改没有影响到外部的`ptr` 。

为了在函数内部能够修改外部指针的指向，我们需要使用二级指针 。将上面的代码修改如下：

```
#include 
#include 

void modify(int **p) {
    *p = (int *)malloc(sizeof(int));
    **p = 10;
}

int main() {
    int *ptr = NULL;
    modify(&ptr);
    if (ptr == NULL) {
        printf("内存分配失败\n");
    } else {
        printf("*ptr = %d\n", *ptr);
        free(ptr);
    }
    return 0;
}
```

在这个版本中，`modify`函数的参数是`int **p` ，`main`函数中传递的是`&ptr` ，即`ptr`的地址 。

在`modify`函数内部，`*p`就是`ptr`本身，通过`*p = (int *)malloc(sizeof(int));`就可以成功修改`ptr`的指向，使其指向分配的内存空间 。这一点清晰地展示出了二级指针所具有的关键意义，其关键意义体现在当需要去改变一个指针变量自身的指向时。

### **9.3 类型决定解引用次数**

在 C 语言中，指针的类型这一因素，会去决定对于数据解引用的次数。**对于一级指针`int *p` ，只需要一次解引用`*p`就可以访问到它所指向的普通变量的值** 。例如：

```
int num = 10;
int *p = #
printf("%d\n", *p);  // 输出10
```

**而对于二级指针`int **p` ，需要两次解引用`**p`才能访问到最终的数据** 。如前面的例子：

```
int num = 10;
int *p1 = #
int **p2 = &p1;
printf("%d\n", **p2);  // 输出10
```

同理，对于三级指针这个概念来说，如果是使用像int _p这样的代码形式来进行定义的场合，那么为了能够访问到最终的数据结果，操作者必须执行三次解引用的动作，也就是要通过类似于_p这样的写法来完成这一过程。

这是因为在指针类型的定义里面，斜杠星号的符号数量是决定指针层级关系的那个关键因素，每增加一个斜杠星号的符号，就意味着间接性多了一层，所以在访问数据的那个时候，就需要多进行一次解引用的操作。

理解了这一点了以后呢，对于正确使用指这件事情来说是非常非常关键的，这样能够避免出现解引用错误这种状况的发生。

### **9.4 画图 + 分类型，比死记硬背更有效**

在学习二级指针以及复杂的指针概念时，画图和分类型理解的方法比死记硬背更加有效。通过画图的方式，我们是可以非常直观地去展示指针彼此之间的指向关系、还有对应的内存布局情况的。比如前面多次提到的用图来表示`p` 、`*p` 、`**p`的内存模型：

```
+--------+
| num    | 变量num，值为10
+--------+
    |
    |  &num，num的地址，假设为0x1000
    v
+--------+
|   p1   | 一级指针p1，存放num的地址0x1000
+--------+
    |
    |  &p1，p1的地址，假设为0x2000
    v
+--------+
|   p2   | 二级指针p2，存放p1的地址0x2000
+--------+
```

从图中可以清晰地看到`p2`指向`p1` ，`*p2`得到`p1` ，`**p2`得到`num`的值 。这种直观的、直接能够看得到的展示方式，能够帮助我们更好地去理解工作原理。这个工作方式就是指针的工作原理。

同时，分类型去理解指针这一件重要的事情是不可忽视的。我们要知道不同类型的指针 （像一级指针、二级指针、数组指针、指针数组这样的一些东西） ，在定义这个动作和使用这个方法上，以及在内存布局的这种状态中，都存在各自不同的特点。

通过把不同类型的指针进行分类学习这个过程，再通过对比这种办法，我们能够在加深对于指针概念理解这个方面起到好的作用，同时也能够避免把这些东西混淆起来的现象出现。

比如，把二级指针和一级指针放在一起比较一下，明确它们在存储的内容和解引用的方式上有哪些不同的地方；再把数组指针和指针数组进行比较，分清它们从本质上来说到底是指针还是数组。

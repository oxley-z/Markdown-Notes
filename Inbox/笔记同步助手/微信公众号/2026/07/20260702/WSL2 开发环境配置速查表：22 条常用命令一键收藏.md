长话短说，Windows 上想搭一个靠谱的 Linux 开发环境，现在最省事的办法就是 WSL2。

先用管理员身份打开 PowerShell，输入

wsl --install

正常情况下，这一条命令会自动启用 WSL，并安装默认 Ubuntu。

如果提示错误，先看自己电脑windows更新有没有被禁用。

装完重启电脑。

如果想指定版本，可以先看列表

wsl --list --online

再装 Ubuntu 24.04

wsl --install -d Ubuntu-24.04

如果你电脑以前装过 WSL，建议补一条

wsl --set-default-version 2

装完之后，开始菜单里会多一个 Ubuntu。

第一次打开会让你设置 Linux 用户名和密码。这个密码不是 Windows 密码，是以后用 sudo 时输入的。

记住就行。

别设成 123456，虽然是在自己电脑上，但也别太奔放。

装完先检查一下。

wsl --list --verbose

看到 VERSION 是 2，就说明是 WSL2。

然后进 Ubuntu，先更新系统。

sudo apt update

sudo apt upgrade -y

接下来再装 Miniconda、Git、VS Code WSL 扩展。

项目建议放在 Linux 的 home 目录里，不要长期放在 /mnt/c/Users 下面开发。偶尔拿文件没问题，但 Node 那种几万个小文件的项目放跨系统路径里跑，电脑没骂你已经算有素质了。

WSL2 不神秘。

它最大的价值就是让 Windows 用户不用为了开发环境折腾半天。

打开 Ubuntu，进入项目目录，敲命令，写代码。

公众号名称：AI不硬核

作者名称：一口吞天

发布时间：2026-05-22 21:15

不知道你们有没有跟我一样的感受，那就是来自各个平台的收藏夹，长年累月积累下来，多的都害怕去点开看了，可以说是多的可以吃灰了。但是偶尔要用的时候，又根本想不起来收藏在哪里了。

![[Inbox/笔记同步助手/微信公众号/2026/07/images/eef50a84ed5070e849fe4fbb1a132899_MD5.jpg]]

爱收藏是好事，但是想回去找的时候，得先回忆下是在哪个平台收藏的，大概率是忘记了的，得一个一个平台点开去看，点开平台后还得慢慢划着看封面哪条才是要找的收藏，说实话我在写这部分内容的时候就已经感觉到这种找收藏的方式有多累了...

虽然大部分平台的收藏夹都有搜索功能，但是搜关键词吧，也总是不对味，并且一个个平台搜也很麻烦，有时候翻也翻不到，就放弃了。

那么今天，我们就来解决这个问题！

我的方案是用Hermes加Obsidian搭建本地知识库。

先说清楚一个概念，免得评论区有人困惑，很多人听到「知识库」，第一反应这不就是RAG吗。

不是滴。完全不是。

RAG的工作方式是，每次你提问，它都临时着急忙慌地去翻你的文档，把相关片段捞出来，拼一个答案给你。所以每次提问都是一次全新的检索，积累不了任何东西，就像我们看书，大部分时间是看过之后就忘，下次还得重新翻。

而我们这次做的这个方案，是把你需要收藏的内容发给AI，AI帮你消化一遍，提取出里面的关键实体和核心概念，或者是你想让AI提取的任何东西，AI会将这些内容之间的关系，存成结构化的笔记，相当于提炼精华并自动分类，然后存到你的电脑上，你下次问相关的问题，或者记忆模糊了，大概问一下关键信息，AI会直接读笔记给你找出来，或者推荐给你和你模糊记忆高度匹配的收藏，这样就不用再从原始文档里临时拼凑。

更重要的是，这些收藏之间是相互连接的，比如你打开一个叫「Claude Code」的实体页，里面会列出所有提到Claude Code的文章以及所有相关概念，或者你想看「AI Agent」这个概念，里面也会列出关于AI Agent的所有东西。

![[Inbox/笔记同步助手/微信公众号/2026/07/images/0afb01e87768f718248a05d0bd82093b_MD5.jpg]]

就像你有了一个私人图书管理员，他帮你看完书之后把核心内容融进一个不断生长的知识体系里。

而这个体系的每一个节点，都是互相连通的。

你看到这可能会想很复杂，不不不一点都不。接下来请跟着我的步骤一步步实操吧！

你需要装的东西就两个。

一、安装Obsidian

Obsidian是一个免费的本地笔记工具，跨Windows、Mac、Linux，它最核心的特点是双向链接，你在笔记里打两个方括号，比如输入“\[\[transformer\]\]”，它就会自动变出一个链接。如果那篇笔记存在，点进去就能看。你不需要手动维护关系，Obsidian会自动帮你做。

```
#Obsidian官网指路
https://obsidian.md/
```

![[Inbox/笔记同步助手/微信公众号/2026/07/images/858f9bd0eeebb7caaf2e6e5cefdf656d_MD5.jpg]]

打开官网根据自己设备选择对应安装包下载即可。

![[Inbox/笔记同步助手/微信公众号/2026/07/images/19a05ed4ef24eea43b60b1e0a1642df5_MD5.jpg]]

Windows端的安装包文件大小是281.83M，下载之后打开exe文件，选择安装路径（C盘不够大的记得装到其它盘）再点击安装就装好了，这一步没有任何额外设置，也不用点很多次“下一步”。

![[Inbox/笔记同步助手/微信公众号/2026/07/images/3793113f892962c3245a9338bb6cea4d_MD5.jpg]]

打开之后会让你新建或者打开一个仓库，通俗讲就是让你选择一个文件夹来存放你的收藏笔记，如果你跟我一样第一次使用这个软件，就点击新建仓库旁边的创建，起个仓库名字，再点击浏览选择文件夹创建路径，

![[Inbox/笔记同步助手/微信公众号/2026/07/images/6133e9f09c609d1bdbe22d4d8312f61f_MD5.jpg]]

名称和路径都设置好之后点击最下方的创建按钮，就进入Obsidian界面啦，刚进来就是一页白纸，接下来我们需要告诉Hermes我们这个收藏夹文件夹的路径，Hermes会帮你建好整个Wiki结构并随着你的命令不断填充笔记，你会看着自己的知识库一点点丰富，随着你收藏的录入，你的知识库就能慢慢从一粒尘埃变成星辰大海，amazing！

![[Inbox/笔记同步助手/微信公众号/2026/07/images/ade8d26ef030d483e7e36e825e23b474_MD5.jpg]]

![[Inbox/笔记同步助手/微信公众号/2026/07/images/3a771a6837c01dac218b9319055952ca_MD5.jpg]]

二、安装Hermes

Hermes Agent 应该不用过多介绍了吧，和小龙虾差不多，但是Hermes Agent内置了一个叫llm-wiki的知识库Skill，这意味着它天生就会按一套规范来操作知识库。你不需要教它怎么提取实体、怎么创建索引、怎么加双向链接。它出厂就能自动帮你把文档整理成结构化笔记，自动加双向链接，自动维护索引。

```
#Hermes Agent官网指路
https://hermes-agent.nousresearch.com/
```

安装也特别简单，按住Win+r，输入cmd

![[Inbox/笔记同步助手/微信公众号/2026/07/images/4ed6c86b559675aa0c6a9420cfc8e62e_MD5.jpg]]

在弹出的命令行提示窗口中输入wsl后按回车键进入wsl，然后输入下面这串指令

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

就会自动下载安装了，注意如果你是windows系统，Hermes是会装到wsl中，wsl也就是运行在Windows上的Linux系统，有点像套娃，这是微软官方的东西而且免费，而且安装到wsl中也能一定程度上保证原生系统的安全，Hermes官方也是推荐安装到wsl中。

如果你没安装过wsl，那就装一个。

按键盘上的 Win 键，搜索框直接打字 powershell，看到「Windows PowerShell」后 → 以管理员身份运行。

![[Inbox/笔记同步助手/微信公众号/2026/07/images/9e2ec72d28c181d62f04e215bc4ecc08_MD5.jpg]]

会弹出一个蓝底白字的窗口，把下面这行粘进去，回车：

```
wsl --install
```

然后等着。它会自动下载 Ubuntu（一个 Linux 发行版），装完后会让你创建一个 Linux 用户名和密码。用户名和密码最好自己记一下。

注意：输密码的时候屏幕不会显示任何东西，连 （空格）都不显示，正常打就行，打完回车。

重启电脑后，WSL就装好了。

装好后回到这一步开头，输入那串Hermes安装指令即可。

输入后你会看到一堆下载进度条滚过去，大概一两分钟。最后显示类似Hermes Agent installed successfully 就说明装好了。

装完之后，关掉当前这个 WSL 窗口，重新打开一个新的 WSL 窗口（重新打开命令提示符并输入WSL）。这一步是为了让 hermes 命令生效。官方也是要求最好这么做。

然后在新窗口中进入WSL后，输入hermes setup，然后回车。

它会问你几个问题：

\- 选模型供应商：用方向键上下选，回车确认。国内用户建议选 deepseek，现在的deepseek v4 pro真的是好用又相音，我给到夯！

![[Inbox/笔记同步助手/微信公众号/2026/07/images/0645d3e3ea01aee95cf3ffe04c052b75_MD5.jpg]]

附上Deepseek开放平台的网站，在这里去拿Api Key

```
#Deepseek开放平台
https://platform.deepseek.com/
```

\- 填 API Key：去对应供应商的网站注册拿一个 Key，粘贴进去。

\- 其他选项全部回车用默认就行。

配置完就搞定了。

如果电脑配置高的话需要本地配置的话可以参考我这篇文章。

## 三、告诉Hermes你的收藏夹路径并配置规则

复制第一步创建的收藏夹的文件路径，告诉hermes这个路径，并加上规则。

```
我的知识库目录是F:\Ai\Hermes_Bookmarks
规则：
1. 只有我明确说"写入知识库"时，才可以写入知识库。
2. 只有我明确说"结合知识库"时，才先检索知识库再回答。
3. 所有知识页使用 Markdown 和 [[双向链接]]。
4. 使用 LLM Wiki 文件结构管理知识库。
```

在这里感谢X博主@Roland.W分享的提示词

发给hermes后它会记录下规则并开始整理收藏夹路径

![[Inbox/笔记同步助手/微信公众号/2026/07/images/ba6a33aaca856d468df1197accd4058e_MD5.jpg]]

![[Inbox/笔记同步助手/微信公众号/2026/07/images/d00467fe78d8fe6d3f49e6d1506356c4_MD5.jpg]]

## 四、启动！往里丢收藏

用的时候也很简单，记住三条规则就行。

规则一，想存东西就说「写入知识库」。

不管是你刷X看到的好文章，还是公众号上的深度内容，或者你自己写的一段笔记。直接说「把这个写入知识库」，Hermes就库库帮你整理。

规则二，想查东西就说「结合知识库」。

你要问一个问题，但希望AI基于你已经积累的知识来回答，就加一句「结合知识库」。比如「结合知识库，我之前收藏的文章里，关于AI Agent有哪些核心观点？」

你想不起来是收藏的精确内容了，可以说个大概，让hermes结合知识库给你匹配出来，后面也有相关测试，你想想未来某一天，你想起来有条收藏刚好需要用到，换做平时也许你要翻好几个平台找好久，但是假如你正好之前将这条收藏配置到了知识库，于是你唤起hermes，hermes几秒钟就给你翻出来了，那一刻说不准会有种久旱逢甘霖的爽感。

Hermes会去你的知识库里检索相关页面，整合之后给你一个完整的回答，而且标注来源。

普通的聊天，比如「规划去新疆的旅行计划」，Hermes不会去翻你的知识库。你的知识库不会被无关对话污染（除非你之前将这条旅行计划录入过知识库并提示Hermes调用）。

规则三，想看图谱就打开Obsidian。

把你建好的 wiki/ 目录，拖进Obsidian当Vault用。然后你会在Graph View里看到一个知识网络图。

每一个节点是一篇笔记，每一条线是一个关联。你能一眼看到哪些知识是枢纽，哪些是孤岛。你能在里面自由跳转，顺着链接一路逛下去，发现你之前根本没想到的关联。

这种感觉太爽了。就像你种了一片森林，然后你可以在里面散步。

收藏夹是互联网时代最大的自我欺骗装置。

我们以为「存了」等于「会了」，以为「看过」等于「懂了」（也可能没看）。但这种感觉是假的，就像你买了健身卡就觉得自己已经瘦了三斤，其实什么都没变。

Hermes + Obsidian这套东西最值得推荐的，不是它的自动化能力有多强，也不是它能帮你找到尘封多年的记忆，而是它逼着你面对一个事实。知识不会自动变成你的，你得去读、去关联、去想、去用。

这套系统帮你省掉的是机械劳动，不是思考本身。

它帮你整理好、链接好、索引好，但阅读和消化的功夫还是你的。

我觉得这才是 AI 跟人之间最健康的关系。AI 干它擅长的，你干你擅长的。

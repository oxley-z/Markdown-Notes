最近在刷 GitHub 热榜，会发现一个明显趋势：  
Claude Code 不再只是写代码，而是在“长出能力模块”  
而这10个Skill，基本定义了当前生态的核心方向👇  
  
前10个Skill在做什么？  
1\. andrej-karpathy-skills  
👉 用一个 CLAUDE.md 文件直接约束模型行为  
→ 本质是“系统级 Prompt”，让输出更稳定可控  
  
2\. claude-mem  
👉 给 Claude 加上“长期记忆”能力  
→ 能跨 session 记住信息，适合持续协作  
  
3\. multica  
👉 多 Agent 任务协作系统  
→ 可以拆任务、分配执行、跟踪进度  
  
4\. free-claude-code  
👉 提供免费使用 Claude Code 的方式  
→ 降低门槛，加速生态扩散  
  
5\. claude-skills（合集库）  
👉 汇总大量现成 Skills  
→ 相当于“技能应用商店雏形”  
  
6\. claude-context  
👉 把整个代码库变成上下文  
→ 让 Claude 能理解复杂项目结构  
  
7\. wiki-skills  
👉 自动构建和维护知识库  
→ 适合文档管理 / 知识沉淀  
  
8\. OmegaWiki  
👉 Claude驱动的研究型 Wiki  
→ 更偏深度分析和长期知识演化  
  
9\. claude-plugin-market  
👉 Skill/插件市场  
→ 支持技能发现、安装、复用  
  
10\. agent-skill-template  
👉 Skill开发模板  
→ 标准化创建自己的 Skill  
  
一句话总结：  
这10个项目拼在一起，其实是在做同一件事：  
把 Claude 从“工具”，变成“可扩展的操作系统”

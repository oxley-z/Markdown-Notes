```c
//带参宏的参数a,b是表达式
#define MAX(a,b) ({\
					typeof(a) _a = a;\	----typeof是获取类型
					typeof(b) _b = b;\
					(void)(&_a == &_b);\----判断参数a b的类型是否一直
					(_a)>(_b)?(_a):(_b);\
				})
1. { }内包含的是一中不能赋值的表达式，因此在预处理宏替代时候回出错，因此加（）转换成可以赋值的表达式。
2.(_a)>(_b)?(_a):(_b); 加括号是优先级的问题，_a是由于自增和自减的问题
3.(void)(&_a == &_b)；判断参数a b的类型是否一致，不一致给出警告，不会报错的
```

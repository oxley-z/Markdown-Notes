# 什么是 `using namespace std;`？

**`namespace`（命名空间）：** 类似于电脑里的“文件夹”。不同文件夹里可以有同名的文件而不会冲突。C++ 的标准库把它的所有工具（如 `cout`、`cin`、`vector` 等）都放在了一个名叫 **`std`**（standard 的缩写）的“文件夹”里。

# `<< std::endl`的作用

- **换行**（打印一个 `\n`）
- **刷新缓冲区**（强制把内容立即推送到屏幕上）

只有当你有 **“立刻让文字出现在屏幕上”** 的强需求时（比如程序在下一步可能会卡住或崩溃，你需要实时日志），才必须刷缓冲区。此时也可以使用更高效的 `std::flush`：

```c++
std::cout << "正在加载，请稍候..." << std::flush; // 实时显示且不换行
```
